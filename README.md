# ХЪСЪЛ — GitHub Pages

Това е актуалната версия на приложението „ХЪСЪЛ“ с новия 7-дневен хранителен план.

Включва:

- точни рецепти за еър фрайър, мултикукър и плот;
- общи количества за вечеря и обяд на следващия ден;
- порциите на съпругата във всички общи хранения;
- три отделни списъка: Пазар 1, Пазар 2 и Месечен запас.

## Публичната страница на предизвикателството (`story.html`)

`story.html` е отделна публична страница с 3D сцена (Three.js) — входът към предизвикателството.
Хората влизат, виждат четирите неща и избират откъде да започнат: **тренировки, хранене, книги,
система и навици**. Клик върху плочка — или директно върху плуващия 3D обект в началото — води
към съответния раздел.

- Адресът ѝ е `<адресът на GitHub Pages>/story.html`.
- Приложението (`index.html`) не е променяно — страницата само води към него.
- Разделите засега са скелет с етикет „Скоро“. Съдържанието се попълва след това.
- Датата на старта е в началото на скрипта (`START`) — оттам се смятат текущата седмица и прогресът.
- Three.js е локално копие в `vendor/three.min.js` (MIT), а шрифтовете Unbounded и Manrope
  (SIL Open Font License) са в `assets/fonts/` — страницата работи офлайн, без външни доставчици.

## Публикуване

1. Качи всички файлове и папката `assets` в основната директория на GitHub хранилището.
2. Отвори **Settings → Pages**.
3. Избери **Deploy from a branch → main → /(root)** и натисни **Save**.
4. Изчакай GitHub Pages да покаже публичния адрес.

Важно: качи съдържанието на тази папка, а не ZIP файла.
