# ХЪСЪЛ — GitHub Pages

Това е актуалната версия на приложението „ХЪСЪЛ“ с новия 7-дневен хранителен план и новия 8-седмичен тренировъчен цикъл.

Включва:

- точни рецепти за еър фрайър, мултикукър и плот;
- общи количества за вечеря и обяд на следващия ден;
- порциите на съпругата във всички общи хранения;
- три отделни списъка: Пазар 1, Пазар 2 и Месечен запас;
- 8-седмичен цикъл „Горна/Долна част“ + три кратки Core сесии вкъщи, със старт неделя, 6 септември 2026;
- дневник по конкретна дата (серии, тежест и повторения) и запазена история от старата програма.

## Публикуване

1. Качи всички файлове и папката `assets` в основната директория на GitHub хранилището.
2. Отвори **Settings → Pages**.
3. Избери **Deploy from a branch → main → /(root)** и натисни **Save**.
4. Изчакай GitHub Pages да покаже публичния адрес.

Важно: качи съдържанието на тази папка, а не ZIP файла.

## Обновяване на инсталираното приложение

Новият service worker използва кеш `hustle-v8-training-cycle-2026-09-06` и зарежда първо актуалната начална страница от мрежата. След качване затвори напълно приложението на iPhone и го отвори отново. Ако още се вижда стара версия, отвори GitHub Pages адреса веднъж в Safari и презареди.
