# ХЪСЪЛ — GitHub Pages

Това е актуалната версия на приложението „ХЪСЪЛ“.

## Публикуване

1. Качи всички файлове и папката `assets` в основната директория на GitHub хранилището.
2. Отвори **Settings → Pages**.
3. Избери **Deploy from a branch → main → /(root)** и натисни **Save**.
4. Изчакай GitHub Pages да покаже публичния адрес.

Важно: качи съдържанието на тази папка, а не ZIP файла.

## Обновяване на инсталираното приложение

Новият service worker използва кеш `hustle-v6-2026-08-11` и зарежда първо актуалната начална страница от мрежата. След качване затвори напълно приложението на iPhone и го отвори отново. Ако още се вижда стара версия, отвори GitHub Pages адреса веднъж в Safari и презареди.
