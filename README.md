# ХЪСЪЛ

Mobile-first PWA с хранителния и тренировъчния план на Боби.

## Качване в GitHub Pages

1. Качи **съдържанието** на тази папка в основната директория на хранилището.
2. В GitHub отвори **Settings → Pages**.
3. Под **Build and deployment** избери **Deploy from a branch**.
4. Избери branch **main**, папка **/(root)** и натисни **Save**.
5. Изчакай 1–3 минути и отвори адреса, показан от GitHub Pages.

За iPhone отвори адреса в Safari → Споделяне → Добавяне към Начален екран.

Всички основни данни и изображения са вградени в `index.html`. Файловете `manifest.webmanifest`, `sw.js` и `icons/` осигуряват инсталиране и offline кеш.
